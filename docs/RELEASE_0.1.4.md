# CloneUp 0.1.4

제품 다듬기 릴리스입니다.  
0.1.3 보안 기반 위에 **동기화 화면**, **설치 약관**, **제어판 아이콘**을 보강했습니다.

## 사용자에게 알려 줄 말 (짧게)

1. **동기화** 탭에서 현재 **branch**와 GitHub **상태**를 한눈에 볼 수 있습니다  
   (연결됨 / 올릴 변경 있음 / 새 변경 없음 등).
2. 로컬 폴더 줄 높이·버튼이 맞춰졌고, **최근 폴더**로 다시 고르기 쉽습니다.  
   긴 경로는 가운데를 줄여 보여 주고, 끝 폴더 이름은 남깁니다.
3. 설치 시 **이용약관**에 동의한 뒤 진행합니다.
4. **제어판(앱 및 기능)** 목록에 CloneUp **아이콘**이 표시됩니다.

## 설치

- `CloneUp-Setup.exe` 실행 → 약관 동의 → 설치  
- 0.1.3 위에 덮어쓰기 가능  
- 이전 설치본을 지운 뒤 설치하면 제어판 아이콘이 가장 확실합니다

## 개발자용 변경 요약 (0.1.3 → 0.1.4)

### 동기화 UX
- branch 배지(내용 폭) + 상태 칩 한 줄 배치
- 상태 문구: 초보용 짧은 한국어 완결 문장
- 로컬 폴더 행: 입력·버튼 높이 통일, 새로고침 보조 비중
- 동기화 **최근 폴더** 콤보
- 경로 중간 생략(elide) + 실제 경로는 속성으로 보관

### 만들고 올리기
- 첫 branch 선택(콤보)
- 폴더 변경 시 저장소 이름 자동 갱신

### 설치·아이콘·약관
- Inno Setup `LicenseFile` ← `desin/provision` 약관 추출  
  (`scripts/export_terms_license.py`)
- `UninstallDisplayIcon` / 바로가기 `IconFilename` → `CloneUp.ico` (16–256)
- Qt `load_app_icon`: ICO + PNG 전 크기
- 설치 후 `{app}\legal\`, `{app}\icons\`

## 버전 위치

- `VERSION` · `app/__init__.py` · `installer/CloneUp.iss`
