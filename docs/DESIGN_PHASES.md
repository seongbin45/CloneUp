# UI 디자인 적용 단계 (desin/ 시안 기준)

참고: `desin/CloneUp Window.dc.html`  
팔레트 소스: `app/ui/theme.py`

## 단계

| 단계 | 내용 | 상태 |
|------|------|------|
| **1** | 전역 QSS + theme.py 색 통일 (버튼/탭/입력/로그) | 진행 |
| **2** | 상단 상태 바 레이아웃 (Git 점 + GitHub 상태) | 대기 |
| **3** | 폼 라벨 92px 그리드 정렬 (시안 레이아웃) | 대기 |
| **4** | 로그 헤더 (“실행 로그 / 토큰 마스킹”) | 대기 |
| **5** | DeviceCode 팝업 시안 팔레트 정렬 | 대기 |
| **6** | 교차검증 + 대비/다크모드 상속 점검 | 대기 |

각 단계 후: 앱 기동 → 탭 전환 → 버튼 가독성 확인 → 필요 시 커밋.
