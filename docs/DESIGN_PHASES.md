## 단계

| 단계 | 내용 | 상태 |
|------|------|------|
| **1** | 전역 QSS + theme.py 색 통일 (버튼/탭/입력/로그) | 완료 |
| **2** | 상단 상태 바 레이아웃 (Git 점 + GitHub 상태) | **되돌림 — 홈 IA로 이전** (Git은 문제일 때만 노란 띠, 설정·도움말은 ⋯) |
| **3** | 폼 라벨 92px 그리드 정렬 (시안 레이아웃) | 완료 |
| **4** | 로그 헤더 (“실행 로그 / 토큰 마스킹”) + 패널 여백 | 완료 |
| **5** | DeviceCode 팝업 시안 팔레트 정렬 | 완료 |
| **6** | 교차검증 + 대비/다크모드 상속 점검 (`desin/dark` 토큰) | 대기 → 다크 하위 단계로 분할 |

### 홈 IA 단계 (`desin/CloneUp 홈.dc.html`)

| 단계 | 내용 | 상태 |
|------|------|------|
| **H-A0** | 검증 스크립트·문서 IA 완화 (설정=도달 가능) | 진행 |
| **H-A** | ⋯ 메뉴 · Git 노란 띠 · Ctrl+, / F1 (구 탭 셸 위) | 진행 |
| **H-B** | 홈 셸 + 스캔 + dirty 있음/없음 + 내역 연결 + 구 status 위젯 제거 | 대기 |
| **H-C** | 하위 펼침 정렬 · 시간순 묶음 · porcelain 숫자 | 대기 |

### 다크모드 전용 단계 (한 번에 하지 않음)

시안: `desin/dark/CloneUp Window Dark.dc.html`  
팔레트: `app/ui/theme.py` → `DARK`

| 단계 | 내용 | 상태 |
|------|------|------|
| **D1** | OS 다크 감지 + 기동/변경 시 전역 QSS에 `DARK` 적용 | 완료 |
| **D2** | 하드코드 색 제거 (auth 점, status 라벨 등 → 활성 팔레트) | 완료 |
| **D3** | DeviceCode 오버레이 다크 카드/딤 (`active_palette`) | 완료 |
| **D4** | 로그·힌트·체크 등 잔여 대비 점검 | 완료 |
| **D5** | (선택) 수동 라이트/다크/시스템 설정 | 대기 |

### 앱 아이콘 단계 (한 번에 하지 않음)

시안: `desin/icon/CloneUp Logo.dc.html`  
팔레트 힌트: `#1f6f5c` · `#46a685` · `#f6f2e8` · `#2b2821`  
규칙: 16–32px 단순화 · 여백 ≥ 심볼 높이 25% · 비율/그라디언트 변형 금지  

| 단계 | 내용 | 상태 |
|------|------|------|
| **I1** | 마스터 자산 (`icon-512`, `icon-512-dark`, `mark-glyph`) | 완료 (시안 PNG 스트립 추출) |
| **I2** | 크기 세트 16–256 + `CloneUp.ico` | 완료 |
| **I3** | 런타임 `setWindowIcon` (창/작업표시줄) | 완료 (원본 마크) |
| **I4** | (선택) About 등 UI 내 마크 | 대기 |
| **I5** | exe 패키징 아이콘 연동 | 대기 |
| **I6** | 문서·경로 정리 | 완료 |

자산: `desin/icon/png/` (시안 export) → `scripts/import_design_pngs.py` → `assets/icons/` + `masters/`  
교차검증: `docs/ICON_CROSS_VERIFY.md`

각 단계 후: 앱 기동 → 탭 전환 → 버튼 가독성 확인 → 필요 시 커밋.
