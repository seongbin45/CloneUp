# CloneUp 0.1.2

0.1.1(키 전용 로그인) 위에 **초심자 마찰을 줄인 사용성**을 모았습니다.  
설치 파일에 반영하려면 이 버전의 Setup을 쓰세요.

## 사용자에게 알려 줄 말 (짧게)

1. **로그아웃** 버튼이 상태 표시줄 오른쪽에 있습니다. (연결 끊기)
2. **받기(클론)** 탭: 긴 URL을 붙여도 저장소 주소만 남기고, **브랜치**는 목록에서 고릅니다.  
   - 예: `main (기본 브랜치)`
3. 저장소 URL이 바뀌면 **폴더 이름**도 그에 맞게 다시 잡습니다.
4. 올리기·동기화 안내 문구를 **짧은 한국어**로 다듬었습니다.
5. 로그인·권한 창은 계속 **짧게** 유지합니다. (키 + repo 권한)

## 설치

- `CloneUp-Setup.exe` 실행 → 설치 → 바탕화면/시작 메뉴에서 실행
- Git이 없으면 앱이 설치를 안내합니다
- 이전 0.1.1 설치본 위에 덮어써도 됩니다

## 처음 쓰기 (3분 요약)

1. 위쪽 **GitHub: 로그인** → 키 만들기(repo ✓) → 붙여 넣기
2. **만들고 올리기** / **받기** / **동기화** 탭 중 하나
3. 끝낼 때 상태 표시줄 **로그아웃** (선택)

## 개발자용 변경 요약 (0.1.1 → 0.1.2)

- 상태 표시줄 로그아웃
- 클론 URL 정규화(owner/repo) + 브랜치 목록 선택
- 클론 대상 폴더 이름 리셋
- 동기화·올리기 평이한 상태/오류 문구
- G3·비밀 확인·클론 연결 안내 단축
- 문서: FAILURE_CASES 제품 기준, auth README, wizard `저장소 권한(repo)`

## 의도적으로 남긴 제한 (C)

- GitHub 토큰 발급 화면 문구는 영어(GitHub 쪽)
- 충돌 자동 해결 UI 없음
- PAT 만료는 “추정 안내” 수준 (강제 차단 아님)
