에이전트가 칸을 대신 채웠다면 무효로 보고 다시 하십시오.

## 경로 표 (이게 전부)

| # | 토큰 | 탭 | 기대 | 결과 (수기) |
|---|------|-----|------|-------------|
| **1** | **classic `repo`** | **만들고 올리기** | **성공해야 함** (주 경로) | □ 성공 URL: ____ / □ 실패: |
| **2** | **세분** + **해당 저장소** + **Contents R/W** | **동기화** (이미 있는 저장소 폴더) | **성공해야 함** (보조 경로) | □ 성공 / □ 실패: |
| **3** | **세분** (Contents 등, 새 이름 없음) | **만들고 올리기** | **실패 예상** | 에러 원문: ____ 「다음:」: ____ |
| **4** | classic `repo` (1과 동일 키 OK) | **만들고 올리기** + 폴더에 **`credentials.txt`** (내용 아무 문자열) | **「올릴 수 없음」 G3 차단** · **저장소 미생성** | □ 차단 대화상자 / □ 안 뜸 / □ 저장소가 생김(실패) |

### #3 진짜 검사 항목

실패 자체만이 아니라, 초심자가 이해할 수 있는가:

- [ ] 「다음:」에 **새 저장소 → classic 키** 안내가 있는가  
- [ ] 원문만 (`Resource not accessible by personal access token` 등)이면 **실패 기록** (문구 수정 백로그)

### #4 — 왜 `.env`가 아닌가

| 층 | 역할 | `.env` (새 폴더) | `credentials.txt` (새 폴더) |
|----|------|------------------|----------------------------|
| 기본 `.gitignore` (`DEFAULT_GITIGNORE`) | 커밋 후보에서 제외 | **제외됨** → 업로드 안 됨 | 목록에 **없음** → 후보에 남음 |
| G3 파일명 스캔 (`run_safety_checks` → 발행 대상만) | 차단 대화상자 | **안 돎** (목록에 없음) | **돎** → 「올릴 수 없음」 |

- [ ] 파일 이름을 **`credentials.txt`**(또는 `secret`이 이름에 들어간 파일)로 넣었는가  
- [ ] 「비밀 파일도 진행 (고급)」은 **끈 상태**인가  
- [ ] 차단 시 GitHub에 **새 저장소가 안 생겼는지** 확인했는가  

**하지 말 것:** 새 폴더에 `.env`만 넣고 “G3 안 뜸 = 버그”로 기록하기.  
그 경우 보호는 `.gitignore`가 하고, G3 UI는 설계상 안 뜹니다.

`*.pem` / `*.key` / `id_rsa` 등은 **기본 `.gitignore`에도** 있어서, 새 폴더 스모크 파일명 후보로는 부적합합니다.
