# CloneUp 0.1.5

0.1.4 제품 다듬기 위에 **첫 실행 안내**, **커밋 내역**, **받기 탭 저장소 목록**을 더한 릴리스입니다.

## 사용자에게 알려 줄 말 (짧게)

1. **처음 실행**하면 짧은 시작 안내(5단계)가 나옵니다. 나중에 위쪽 **도움말**에서 다시 볼 수 있습니다.
2. **동기화** 탭 **커밋 내역**으로 지난 시점을 읽기 전용으로 볼 수 있습니다.  
   (작업 중인 폴더는 바뀌지 않습니다. 「이 시점 파일 보기」는 임시 폴더에 꺼냅니다.)
3. **받기** 탭에서 GitHub에 연결되어 있으면 **목록 ▼** 으로 내 저장소를 고를 수 있습니다.  
   연결 전에는 예전처럼 주소만 붙여 넣으면 됩니다.
4. 폴더 경로는 **전체를 그대로** 보여 줍니다.

## 설치

- `CloneUp-Setup.exe` 실행 → 약관 동의 → 설치  
- 0.1.4 위에 덮어쓰기 가능

## 개발자용 변경 요약 (0.1.4 → 0.1.5)

### 온보딩
- 첫 실행 5단계 안내 (`desin/CloneUp 첫 실행 안내`)
- `onboarding_done` QSettings + 상단 「도움말」 재열기

### 커밋 내역
- 읽기 전용 팝업 (목록·변경 파일·스냅샷 추출)
- 첫 커밋 파일 목록: `git diff-tree --root`

### 받기 탭
- 로그인 시 내 저장소 목록 (`list_user_repos`) + **목록 ▼** 버튼
- 미로그인: URL 입력 전용
- `owner/repo` · 목록 라벨 정규화 보완
- `is_logged_in()` 헬퍼

### 기타
- 경로 중간 생략 제거
- `cross_verify` 기대값 정리 (한글 G2 문구·토큰 완전 마스킹)
