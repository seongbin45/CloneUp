목표: 실패 케이스(`FAILURE_CASES.md`)와 약관에만 있던 설명을 **화면 안**에서 평이한 말로 보여 준다.

## 결정 (합의)

| 질문 | 선택 | 이유 |
|------|------|------|
| **힌트 형태** | **탭당 접는 팁 카드 1장** | 공간↓. 접힘=한 줄, 펼침=G1+G2 |
| **필드 아래 상시 회색 글** | 쓰지 않음 (clone 루트 안내는 기존 배너 유지) | 창 길이 부담 |
| **첫 실행 안내** | **적용** (`onboarding_dialog.py`, 7단계) | 예전 표의 「3단계 위저드 보류」는 폐기. 전체화면 모달. 건너뛰기·도움말에서 재개 가능 |

### G3 (적용 · 카피 강화)

- **만들고 올리기** / **동기화 → 올리고 보내기** 직전 `QMessageBox`
- 비밀 **파일명** 후보 (`.env` 등)
  - 체크 안 함 → **차단** + 다음 행동 1)·2) + 오탐(`.env.example`) 안내
  - 체크 함 → 확인 후 진행 + 「내용 스스로 확인」 문구
- 파일 **내용** 개인정보 패턴 (전화·이메일)
  - 확인만 (차단 아님) + **오탐 가능** 명시 (예시 번호 등)
- 공개/비공개 위험을 **평이한 말**로 구분
- 항상: **커밋에 남을 작성자 주소**
  - 체크 **「커밋에 내 이메일 숨기기 (권장)」** (기본 켜짐)
    → 이번 커밋만 GitHub **가림 주소** (PC Git 설정 안 바꿈)
  - 체크 끔 → PC Git `user.email` 사용
  - 공개/비공개는 “누가 보느냐”만 바꿈 (주소 자체를 만들지 않음)
  - 구현: `hide_real_email` → `resolve_commit_identity` / `preview_commit_email`
- 상세: `docs/PII_CROSS_VERIFY.md`


### G4 (적용)

- `app/util/next_action.py` — 기존 오류 문자열 매칭 → `다음: …`
- `_on_fail_msg`: 로그 ERROR 다음 줄 + 실패 대화상자에 동일 문구
- 예: denied/권한 → 재로그인 · 이미 존재하는 경로 → 폴더 이름 변경

### G5 — 성공 후 「다음 할 일」 (적용, V5)

- `app/ui/success_dialog.py`
- **만들고 올리기** 성공: 공개/비공개 의미 · GitHub 열기 · 주소 복사 · 동기화 탭 이동
- **받기** 성공: 저장 위치 · 동기화 탭 안내
- Desktop 튜토리얼 저장소가 아니라 **방금 내 폴더/주소** 기준

각 층 후: 앱 기동 → 탭 전환 → 가독성 확인 → 커밋.

## 키보드 단축키 — F11 전체화면

| 창 | 구현 위치 | 방식 |
|----|-----------|------|
| 메인 창 (만들고 올리기 / 받기 / 동기화 3탭) | `app/ui/main_window.py` `MainController._toggle_fullscreen` | 이미 최상위 `QMainWindow` → `showFullScreen()` / `showNormal()`만으로 전-후 geometry가 정확히 복원됨. Frameless 플래그 조작 불필요 |
| 커밋 내역 팝업 | `app/ui/commit_history_dialog.py` | `QDialog`라서 `Qt.WindowType.Window` 강제 지정 + fullscreen 전환 시 `FramelessWindowHint` on/off 필요 (Windows에서 `showNormal()` 단독 시 창이 사라지거나 크기 0이 되는 문제 회피). 열리면 기본으로 전체화면 진입 |
| 첫 실행 안내 (온보딩) | `app/ui/onboarding_dialog.py` | 위와 동일한 이유로 Frameless 토글 방식. 열리면 기본으로 전체화면 진입 |

공통: 포커스가 어떤 자식 위젯에 있어도 F11이 먹도록 `keyPressEvent` 오버라이드 대신 `QShortcut(QKeySequence(Qt.Key.Key_F11), <window>, activated=...)`을 씁니다.

메인 창은 다이얼로그 두 개와 달리 **처음 열릴 때 자동으로 전체화면 진입하지 않습니다** — 일반 데스크톱 앱 기대와 다르면 오히려 방해가 되므로, F11을 눌러야만 토글됩니다. 안내 문구(`Esc 닫기 · F11 …`)도 다이얼로그의 인-윈도우 타이틀 바에만 있고 메인 창에는 넣지 않았습니다 — OS 타이틀 바만 있고 넣을 자리가 마땅치 않기 때문. (Orca computer-use의 `press-key`는 F11을 지원하지 않아 실제 사용자 입력 재현이 필요하면 PowerShell `SendKeys` 등으로 우회해서 검증했습니다.)
