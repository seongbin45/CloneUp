# CloneUp — 초보자 안내 4층 (단계 적용)

목표: 실패 케이스(`FAILURE_CASES.md`)와 약관에만 있던 설명을 **화면 안**에서 평이한 말로 보여 준다.

## 결정 (합의)

| 질문 | 선택 | 이유 |
|------|------|------|
| **2층 힌트 형태** | 입력란 **아래 회색 한 줄 상시 표시** (아이콘 펼침 아님) | 초보자 대상 — 클릭 전에도 보이게. 창이 길어지면 줄 수를 짧게 유지 |
| **첫 실행 3단계 위저드** | **보류** (1층 탭 한 줄로 대체) | 모달 마찰↓. 필요 시 나중에 `settings` 플래그로 추가 |

## 층별 계획

| 층 | 내용 | 상태 |
|----|------|------|
| **G1** | 탭 상단 한 줄 안내 (항상) | 완료 |
| **G2** | 오해 지점 필드 아래 상시 힌트 | 대기 |
| **G3** | 실행 전 확인 (비밀 파일 목록, 커밋 이메일 공개) | 대기 |
| **G4** | 로그 실패 아래 「다음: …」 행동 한 줄 | 대기 |

### G1 카피

| 탭 | 문구 |
|----|------|
| 만들고 올리기 | 내 컴퓨터 폴더를 GitHub에 처음 올립니다. |
| 받기 | GitHub에 있는 폴더를 내 컴퓨터로 복사합니다. |
| 동기화 | 이미 연결된 폴더의 변경사항을 주고받습니다. |

### G2 예정 (상시 작은 글씨)

| 필드 | 힌트 요지 |
|------|-----------|
| GitHub 주소 | 루트만 (기존 `labelCloneHint` 유지·정돈) |
| 저장소 이름 | 쓸 수 없는 문자 · 원격에 이미 있으면 실패 |
| 공개/비공개 | 공개는 되돌리기 어려움 |
| 로컬 저장소(동기화) | `.git` 없으면 받기·만들고 올리기 먼저 |

### G3 예정

- 비밀 파일 후보 목록 + 「이대로 올리면 인터넷에 공개될 수 있습니다」
- 첫 커밋: 사용할 이메일 표시 + 「커밋에 기록되어 공개됩니다」

### G4 예정

- `clone_ops` / `sync_ops` / `publish` 한국어 메시지 재사용
- 앞에 `다음: …` 만 붙임 (denied → 재로그인, 경로 존재 → 이름 변경 등)

각 층 후: 앱 기동 → 탭 전환 → 가독성 확인 → 커밋.
