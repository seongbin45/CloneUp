# CloneUp — 초보자 안내 4층 (단계 적용)

목표: 실패 케이스(`FAILURE_CASES.md`)와 약관에만 있던 설명을 **화면 안**에서 평이한 말로 보여 준다.

## 결정 (합의)

| 질문 | 선택 | 이유 |
|------|------|------|
| **힌트 형태** | **탭당 접는 팁 카드 1장** | 공간↓. 접힘=한 줄, 펼침=G1+G2 |
| **필드 아래 상시 회색 글** | 쓰지 않음 (clone 루트 안내는 기존 배너 유지) | 창 길이 부담 |
| **첫 실행 3단계 위저드** | **보류** | 모달 마찰↓ |

## 층별 계획

| 층 | 내용 | 상태 |
|----|------|------|
| **G1** | 탭 목적 한 줄 (팁 카드 접힘 헤더) | 완료 |
| **G2** | 오해 지점 요약 (팁 카드 펼침 본문) | 완료 |
| **G3** | 실행 전 확인 (비밀 파일 목록, 커밋 이메일 공개) | 완료 |
| **G4** | 로그 실패 아래 「다음: …」 행동 한 줄 | 대기 |

### 팁 카드 (`app/ui/tip_card.py`)

| 탭 | 접힘 요약 | 펼침 요지 |
|----|-----------|-----------|
| 만들고 올리기 | 처음 올립니다 | 이름 규칙 · 공개의 되돌리기 어려움 · 비밀 파일 |
| 받기 | 복사합니다 | 루트 URL · 폴더 이름 충돌 · 비공개=로그인 |
| 동기화 | 주고받습니다 | `.git` 필요 · 비밀 파일 · push 실패 시 재로그인 |

### G3 (적용)

- **만들고 올리기** / **동기화 → 올리고 보내기** 직전 `QMessageBox`
- 비밀 **파일명** 후보 (`.env` 등) + 「이대로 올리면…」
  - 체크 안 함 → 차단 / 체크 함 → 확인 후 진행
- 파일 **내용** 개인정보 패턴 (전화·이메일) — 참고 `Command-to-commit-changes-from-Git`
  - 확인 대화에 목록 표시 (오탐 가능 → 차단 대신 확인)
- 항상: 커밋 기록 이메일 공개 (`peek_commit_email`)
- 상세: `docs/PII_CROSS_VERIFY.md`

### G4 예정

- `clone_ops` / `sync_ops` / `publish` 한국어 메시지 재사용
- 앞에 `다음: …` 만 붙임 (denied → 재로그인, 경로 존재 → 이름 변경 등)

각 층 후: 앱 기동 → 탭 전환 → 가독성 확인 → 커밋.
