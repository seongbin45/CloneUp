# CloneUp 0.1.7

0.1.6 위에 **연결·권한·설정 다듬기**, **약관·라이선스 배포 반영**, **초심자 안내(온보딩·용어)** 를 묶은 패치 릴리스입니다.

**주 경로:** classic PAT(`repo`) + **만들고 올리기**.  
세분(fine-grained) 키로 **새 저장소 만들기**는 목표가 아닙니다 (기존 저장소 동기화 보조).

## 사용자에게 알려 줄 말 (짧게)

1. GitHub 연결은 **개인 액세스 토큰(키)** 이 기본입니다. 만들고 올리기에는 **classic 키 + 저장소(repo) 권한**을 권장합니다.
2. **설정 → 계정**에서 **권한 다시 확인** · **GitHub 키 목록** · 로그아웃 순서를 쓰기 쉽게 맞춰 두었습니다.
3. **설정 → 정보**에서 **이용약관**, **라이선스(Apache 2.0)**, **오픈소스 고지**를 다시 볼 수 있습니다. 설치 폴더에 `LICENSE`와 `legal\` 도 함께 둡니다.
4. 첫 실행 안내는 **폴더가 두 곳**(내 컴퓨터 · GitHub)부터 설명합니다. 커밋은 아직 내 컴퓨터 안 서고에 남기는 단계입니다.
5. 비밀 파일: 새 폴더의 기본 무시 목록이 `.env` 등을 빼고, 이름이 다른 비밀 파일은 올리기 직전에 막을 수 있습니다.

## 설치

- `CloneUp-Setup.exe` 실행 → 약관 동의 → 설치  
- 0.1.6 위에 덮어쓰기 가능

## 개발자용 변경 요약 (0.1.6 → 0.1.7)

### 인증 · 권한
- X-OAuth-Scopes 쉼표 분리 파싱 · 게이트 전 스코프 새로고침
- 설정 계정: 권한 다시 확인, 키 목록 버튼, 창 너비·버튼 순서
- 연결 마법사 **1순위 = classic `repo`** (만들고 올리기) · 세분 = 동기화 보조
- classic 키 웹에서 scope 수정 가능 안내 정정

### 법적 · 패키징
- 이용약관 v1.1 (PAT·로그아웃·안전 스캔)
- 루트 `LICENSE` (Apache 2.0, Copyright 2026 최성빈) UTF-8
- 설치본 `{app}\LICENSE` · `legal\` (약관·오픈소스 고지)
- PyInstaller `cloneup.spec`에 LICENSE 포함

### UX · 온보딩 · 용어
- 온보딩 다듬기 (히스토리 모드 카드, 1단계 두 곳, 2단계 서고=내 PC)
- 설정 용어 안내 + 사용자 용어 추가(+)
- 팁·동기화 안내 교정, workflow 스코프 실패 시 반응형 도움

### 문서
- 스모크 #4: G3 UI 트리거는 `.env`가 아니라 `credentials.txt` 등 (기본 gitignore 층 구분)
- 결정 문서: SHA 인용 금지 (날짜+커밋 제목)
