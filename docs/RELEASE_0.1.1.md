# CloneUp 0.1.1

## 사용자에게 알려 줄 말 (짧게)

1. **GitHub 연결은 “키”만** 씁니다. (브라우저 장치 코드 방식은 보안상 끕니다.)
2. 키 만들 때 **repo(저장소) 권한**을 꼭 켜 주세요. 안 켜면 친절한 안내 창이 뜹니다.
3. **만료일**은 90일 또는 “없음”을 권장합니다. 만료되면 새 키로 다시 연결하세요.
4. 연결·권한 안내 창은 **짧게** 바뀌었습니다.

## 설치

- `CloneUp-Setup.exe` 실행 → 설치 → 바탕화면/시작 메뉴에서 실행
- Git이 없으면 앱이 설치를 안내합니다

## 처음 쓰기 (3분 요약)

1. 위쪽 **GitHub: 로그인**
2. **새 키 만들기** → repo ✓ · 만료 설정 → 복사
3. 붙여 넣기 → 연결
4. **만들고 올리기** 탭에서 폴더 올리기

## 개발자용 변경 요약

- Device Flow 기본 OFF (`CLONEUP_ALLOW_DEVICE_FLOW=1` 만 개발용)
- PAT 연결 마법사 2단계 + 권한 부족 안내 팝업
- 키 연결 나이 안내 (만료 추정 경고)
- 성공/연결 팝업 가독성 개선
