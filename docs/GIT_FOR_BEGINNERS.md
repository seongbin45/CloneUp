# Git을 초심자에게 와닿게 설명하려면

CloneUp 제품·온보딩·설정 「용어 안내」의 **설명 원칙**입니다.  
**화면 버튼·탭 이름(만들고 올리기, 받기, 동기화, 충돌 취소, 커밋 내역…)은 바꾸지 않습니다.**  
설명만 몸의 경험에 가깝게 붙입니다.

---

## 핵심

피드백이 가리키는 것도 결국 이것입니다.

> 명령어 사전이 아니라  
> **왜 쓰는지 / 언제 쓰는지 / 뭐가 위험한지**가  
> 몸의 경험으로 와닿아야 한다.

클론업 GUI는 그 감각을 탭으로 나눈 것이고,  
깊은 고민은 기능을 끝없이 늘리는 쪽이 아니라  
**같은 비유를 온보딩·상태·실패 메시지·용어 안내에 반복**하는 쪽에 있습니다.

---

## 1. 초심자가 안 와닿는 이유

| 흔한 설명 | 초심자 머리에서 일어나는 일 |
|-----------|---------------------------|
| “분산 버전 관리 시스템” | 단어 세 개 전부 추상 |
| “스냅샷 / 트리 / 해시” | 구현 이야기. 아직 필요 없음 |
| “로컬과 원격” | 두 폴더가 왜 필요한지 모름 |
| “브랜치로 실험” | 실험할 코드가 없음. 먼저 **잃어버리는 공포**가 큼 |
| “협업 도구” | 혼자 과제·포트폴리오일 때는 남의 이야기 |

초심자의 진짜 질문은 보통 이 셋입니다.

1. **이거 안 쓰면 뭐가 망가지나?**  
2. **지금 이 버튼이 내 파일을 어떻게 바꾸나?**  
3. **실수하면 되돌릴 수 있나, 인터넷에 남나?**

와닿는 설명은 이 세 질문에 먼저 답해야 합니다.

---

## 2. 한 줄 핵심

> Git은 “파일을 예쁘게 관리하는 앱”이 아니라,  
> **“나중에 나 자신(또는 다른 장소)이 믿을 수 있게 남기는 기록 습관”** 이다.

클론업이 하는 일:

| 감각 | 앱에서 쓰는 말 (그대로) |
|------|-------------------------|
| 점 찍기 | **커밋** |
| 밖에 사본 두기 | **GitHub** · **만들고 올리기** · **올리고 보내기** |
| 맞추기 | **받기** · **받아오기** · **동기화** |
| 겹쳐서 멈춤 | **충돌** · **충돌 취소** |
| 점 목록 / 되돌리기 | **커밋 내역** |

---

## 3. 비유는 층으로 (제품 단어는 유지)

### 커밋
- 사진 앨범, 게임 세이브에 가깝다.  
- “잘 되는 순간을 안 남기면, 망가진 뒤엔 기억만 남는다.”

### GitHub
- 집 밖 **두 번째 서랍**.  
- 올리기는 이사가 아니라 사본을 두는 일.

### 동기화 (올리고 보내기 / 받아오기)
- 집 노트와 학교 노트 맞추기.  
- “어느 쪽이 새 기록을 더 가졌는지 보고 맞춘다.”

### 충돌
- 같은 문장을 빨간 펜 두 자루로 고침 → 자동 합치기 불가.  
- 죄 아님. 사람 손이 필요해서 멈춤.

### 충돌 취소 vs 커밋 내역
- **충돌 취소**: 합치기 **시도**를 포기하고 직전으로.  
- **커밋 내역**: 남겨 둔 **점**을 보거나 (설정 시) 되돌리기.  
- **서로 다른 버튼.**

---

## 4. 말의 규칙

1. **물건 → 비용 → 행동** 순서 (먼저 왜 망가질 수 있는지).  
2. 영어 명령보다 **화면에 있는 한국어 이름**을 기준으로.  
3. 공포는 **정확한 비용**만 (공개·비밀·이력).  
4. **혼자여도 Git**을 먼저, 협업은 그다음.

---

## 5. 가르치지 않을 것 (의도)

해시, DAG, rebase, 첫 주의 브랜치 전략 그래프.  
대신: 점 / 두 서랍 / 맞추기 / 겹침 / 공개·유출 비용.

풀 Git GUI를 안 하는 것은 약점이 아니라  
**초심자 와닿음을 위한 범위**입니다.  
→ [DIFFERENTIATION.md](DIFFERENTIATION.md)

---

## 6. 앱 안 위치

| 장소 | 역할 |
|------|------|
| 시작 안내 (도움말) | 폴더 둘 · 커밋 · **한 바퀴 루프** · 대가 · 안전 |
| 설정 → **용어 안내** | 화면 말 그대로 + 쉬운 풀어쓰기 (`app/ui/git_terms_ko.py`) |
| 동기화 상태 문구 | 충돌·보낼/받을 커밋의 **왜** |
| 탭 팁 카드 | 각 탭의 **왜** 한 줄 |

용어 카드를 키울 때: **제품 UI 단어는 교체하지 말 것.**
