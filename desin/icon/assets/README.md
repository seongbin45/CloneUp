# `desin/icon/assets/` — 시안 미리보기용 아이콘 복사본

`assets/icons/` 와 비슷한 PNG/ICO가 들어 있을 수 있습니다.  
시안 HTML(`CloneUp Logo.dc.html`)이 `assets/...` 상대 경로로 이미지를 보여 주기 위함입니다.

## 초심자

- **앱이 실제로 쓰는 아이콘**은 `assets/icons/` 입니다.  
- 여기만 고치고 `assets/icons/` 를 안 바꾸면 **창 아이콘은 안 바뀝니다.**  
- `scripts/render_icons.py` 는 보통 둘 다 맞춥니다(미러).

배포 전 확인: 루트에서 Setup 빌드 후 설치본 아이콘 확인.
