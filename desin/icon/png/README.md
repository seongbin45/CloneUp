# `desin/icon/png/` — 디자인 export (selection 캡처)

디자인 도구에서 내보낸 `CloneUp Logo-selection*.png` 를 둡니다.  
아이콘 추출 스크립트(`scripts/import_design_pngs.py`)의 입력입니다.

## 초심자

| 단계 | 할 일 |
|------|--------|
| 1 | 디자인 툴에서 보드/크기 스트립 export → 이 폴더에 저장 |
| 2 | `python scripts\import_design_pngs.py` 또는 `render_icons.py` |
| 3 | `assets/icons/` 결과 확인 |
| 4 | 커밋 후 Setup 재빌드 |

파일 이름이 길어도 괜찮습니다.  
**실행 중인 앱은 이 폴더를 직접 읽지 않습니다.**
