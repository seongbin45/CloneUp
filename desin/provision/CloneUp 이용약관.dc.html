클론업(CloneUp) 이용약관

버전 1.1 시행일 2026년 8월 9일 대상 Windows 데스크톱 애플리케이션
배포 전 확인 사항. 운영자 정보는 모두 확정되었습니다. 남은 것은 법률 검토이며, 이 문서는 변호사가 작성한 것이 아닙니다. 본문은 앱의 실제 동작을 근거로 작성되었고 그 근거는 부록에 정리되어 있습니다.

제1조 (목적)

이 약관은 최성빈(이하 "운영자")이 제공하는 데스크톱 애플리케이션 클론업(CloneUp, 이하 "이 앱")의 이용 조건과 절차, 운영자와 이용자의 권리·의무 및 책임을 정하는 것을 목적으로 합니다.

제2조 (정의)

  1. "이 앱"이란 로컬 폴더와 GitHub 저장소 사이의 복제·게시·동기화 작업을 그래픽 화면으로 수행하도록 돕는 Windows용 프로그램을 말합니다.
  2. "이용자"란 이 약관에 동의하고 이 앱을 설치·실행하는 자를 말합니다.
  3. "GitHub"란 GitHub, Inc. 가 운영하는 저장소 호스팅 서비스 및 그 API를 말합니다.
  4. "액세스 토큰"이란 이용자가 GitHub 계정 연동 시 GitHub로부터 발급받아 이 앱이 GitHub API 및 Git 인증에 사용하는 인증 수단을 말합니다.
  5. "로컬 폴더"란 이용자의 컴퓨터에 있는 폴더로서, 이 앱이 Git 명령의 대상으로 지정한 경로를 말합니다.

제3조 (약관의 효력 및 변경)

  1. 이 약관은 이용자가 설치 관리자에서 이 약관에 동의하고 설치를 진행한 시점부터 효력이 발생합니다. 동의한 약관의 전문은 설치 이후 앱의 설정 화면에서 언제든지 다시 확인할 수 있습니다.
  2. 운영자는 필요한 경우 이 약관을 변경할 수 있으며, 변경된 약관은 저장소의 README 및 앱 설치 관리자에 게시함으로써 공지합니다. 이 경우 앱의 설정 화면에 표시되는 약관도 함께 갱신됩니다.
  3. 이용자에게 불리한 변경의 경우 운영자는 시행일로부터 30일 전에 공지합니다. 이용자가 변경에 동의하지 않는 경우 이 앱의 이용을 중단하고 삭제할 수 있습니다.

제4조 (이용 자격)

이 앱의 주요 기능은 GitHub 계정을 필요로 합니다. 따라서 이용자는 GitHub의 이용약관에 따라 유효한 계정을 보유하고 그 연령 요건을 충족해야 합니다. 이 앱은 이용자의 계정 자격을 별도로 심사하지 않습니다.

제5조 (GitHub 계정 연동 및 권한 범위)

  1. 이 앱의 이용자 인증 방식은 개인 액세스 토큰(Personal Access Token) 입력입니다. 이용자가 GitHub 웹사이트에서 직접 토큰을 발급하여 이 앱에 입력하면, 이 앱은 그 토큰으로 GitHub API 및 Git 인증을 수행합니다.
  2. 이 앱은 이용자의 GitHub 아이디·비밀번호·2단계 인증 코드를 입력받거나 저장하지 않습니다. 로그인은 이용자가 GitHub 웹사이트에서 직접 수행합니다.
  3. 권한 범위는 이용자가 토큰을 발급할 때 스스로 정합니다. 이 앱은 세분화된 토큰(fine-grained) 으로 사용할 저장소 하나에 대해 콘텐츠 읽기·쓰기 권한만 부여하는 방식을 권장합니다. 기존 방식(classic)의 토큰을 사용하는 경우에는 repo 범위가 필요하며, 이는 계정의 공개 및 비공개 저장소 전체에 대한 읽기·쓰기를 포함하는 넓은 범위입니다. 비공개 저장소를 만드는 기능이 이 범위를 요구하기 때문입니다.
  4. 이 앱은 OAuth 장치 인증 방식(Device Authorization Grant)을 기본적으로 사용하지 않습니다. 프로그램에 포함되어 배포되는 OAuth 식별자(client_id)는 감출 수 없고, 이를 그대로 가져다 쓰는 다른 프로그램이 동일한 GitHub 승인 화면을 띄워 이용자의 토큰을 가로챌 수 있기 때문입니다. 이 경로는 유지보수자가 환경 변수 CLONEUP_ALLOW_DEVICE_FLOW 로만 켤 수 있는 실험 기능이며, 일반 이용자에게는 제공되지 않습니다.
  5. 이용자는 GitHub 계정 설정의 토큰 목록에서 언제든지 해당 토큰을 삭제하여 이 앱의 접근 권한을 즉시 없앨 수 있습니다.

제6조 (액세스 토큰의 저장 및 관리)

  1. 발급된 액세스 토큰과 승인된 권한 범위는 이용자 컴퓨터의 운영체제 자격 증명 저장소(Windows 자격 증명 관리자)에 CloneUp 항목으로 저장됩니다. 운영자는 이용자의 토큰을 수집하거나 보관하지 않습니다.
  2. 이 앱은 로그 화면에 출력되는 모든 문장과 오류 메시지에 마스킹 처리를 적용하여, 알려진 형식의 토큰이 그대로 표시되지 않도록 합니다.
  3. 이 앱은 Git 원격 주소(remote URL)에 토큰을 저장하지 않습니다. 인증이 필요한 작업에는 임시 자격 증명 파일을 사용하고 작업 종료 시 이를 삭제하며, 게시 직후에는 저장소 설정 파일과 원격 주소에 토큰이나 토큰 형태의 문자열이 남지 않았는지 검사하여, 남은 경우 오류로 처리합니다.
  4. 이 앱은 메인 화면 및 설정 화면에서 로그아웃 기능을 제공합니다. 로그아웃하면 이 컴퓨터의 자격 증명 저장소에 저장된 토큰과 권한 범위가 삭제됩니다. 또한 다시 로그인하는 경우, 토큰이 무효가 된 경우, 또는 저장된 권한 범위가 부족하여 재인증이 필요한 경우에도 저장된 토큰이 삭제되고 새 토큰으로 대체될 수 있습니다.
  5. 연동을 완전히 해제하려면 제5조 제5항에 따라 GitHub 계정 설정에서 해당 토큰을 삭제하는 것이 안전합니다. 앱에서 로그아웃한 뒤에도 GitHub 쪽에 토큰이 남아 있을 수 있으며, 자격 증명 저장소에 남은 항목은 Windows 자격 증명 관리자에서 직접 삭제할 수 있습니다.
  6. 이용자 컴퓨터의 계정 보안, 운영체제 접근 통제, 악성코드 감염 방지는 이용자의 책임입니다.

제7조 (로컬 파일의 변경)

  1. 이 앱은 이용자가 지정한 로컬 폴더에서 Git 명령을 실행하며, 그 결과로 파일과 폴더가 생성·변경·이동될 수 있습니다. 여기에는 기본 브랜치 이름을 main 으로 하는 저장소 초기화, 폴더 전체의 변경 스테이징, 커밋, 원격 주소 등록, 푸시, 원격 내용 병합이 포함됩니다.
  2. 게시 시 대상 폴더에 .gitignore 파일이 없으면 이 앱이 기본 .gitignore 파일을 새로 생성합니다. 이용자는 그 내용을 확인할 책임이 있습니다.
  3. 원격 내용을 받아오는 과정에서 병합 충돌이 발생할 수 있습니다. 이 앱은 충돌 내용을 자동으로 해결하지 않습니다. 이용자는 충돌을 취소하거나 편집기에서 직접 해결해야 합니다.
  4. 이용자는 중요한 데이터에 대해 이 앱과 무관한 별도의 백업을 유지해야 합니다.

제8조 (비밀 정보 점검 기능의 한계)

  1. 이 앱은 게시·커밋 전에 비밀 정보로 보이는 파일이 있는지 점검하여 경고하거나 진행을 막을 수 있습니다.
  2. 점검은 주로 파일 이름·경로 패턴과, 일부 파일 내용 패턴(예: 개인 키 형식, 알려진 토큰 형태)에 기반한 보조 기능입니다. 모든 비밀 정보를 빠짐없이 찾지 못하며, 점검 결과가 없다는 사실이 비밀 정보가 포함되지 않았음을 보증하지 않습니다.
  3. 설정에서 점검을 끄거나, 고급 옵션으로 일부 경고를 무시하고 진행한 경우에도, 명백한 내용 기반 비밀 값은 계속 막을 수 있습니다. 경고를 무시하고 진행한 결과로 인한 비밀 정보 노출의 책임은 이용자에게 있습니다.

제9조 (공개 게시의 비가역성)

저장소를 공개로 생성하거나 공개 저장소에 내용을 푸시한 경우, 해당 내용은 제3자에 의해 열람·복제·색인될 수 있으며 사후에 삭제하여도 완전한 회수가 보장되지 않습니다. 이용자는 게시 전에 공개 여부와 포함 파일을 반드시 확인해야 합니다. 또한 이 앱은 GitHub 저장소를 삭제하는 기능을 제공하지 않으므로, 삭제는 GitHub 웹사이트에서 직접 수행해야 합니다.

제10조 (이용자의 의무)

이용자는 다음 행위를 하여서는 안 됩니다.

  1. 타인의 GitHub 계정 또는 액세스 토큰을 무단으로 사용하는 행위
  2. 권리 없는 저작물, 타인의 개인정보, 법령에 위반되는 자료를 이 앱을 통해 게시하는 행위
  3. GitHub의 이용약관, API 이용 제한 또는 남용 방지 정책을 위반하는 방식으로 이 앱을 사용하는 행위
  4. 이 앱을 자동화 수단으로 개조하여 GitHub에 과도한 요청을 발생시키는 행위
  5. 이 앱의 안전장치를 우회하기 위하여 프로그램을 변조하는 행위

제11조 (실험적 기능)

이 앱에는 실험적 브라우저 자동화 기능이 포함되어 있습니다. 이 기능은 환경 변수 CLONEUP_PLAYWRIGHT 의 값이 1, true, yes, on 중 하나일 때에만 동작하며, 변수가 설정되어 있지 않으면 비활성입니다. 별도의 추가 구성요소 설치도 필요하므로 일반적인 설치 상태에서는 사용되지 않습니다. 활성화된 경우에도 실패하면 이용자가 직접 승인하는 경로로 되돌아갑니다. 또한 이 기능은 제5조 제4항의 장치 인증 경로에서만 쓰이므로, 그 경로가 꺼져 있는 기본 상태에서는 동작하지 않습니다. 실험적 기능은 사전 통지 없이 변경·제거될 수 있고 정상 동작이 보장되지 않으며, 이를 활성화하여 사용하는 경우의 위험은 이용자가 부담합니다.

제12조 (제3자 서비스)

  1. 이 앱은 기능 수행을 위해 GitHub의 서비스(github.com, api.github.com) 및 이용자 컴퓨터에 설치된 Git 프로그램에 의존합니다.
  2. 이용자가 GitHub를 이용함에 있어서는 GitHub의 이용약관과 개인정보처리방침이 적용됩니다.
  3. 운영자는 GitHub의 서비스 중단, 정책 변경, 요청 한도 제한, Git 프로그램의 결함으로 인한 장애에 대하여 책임을 지지 않습니다.

제13조 (개인정보)

  1. 이 앱은 운영자의 서버를 두지 않으며, 이용 기록·통계·오류 정보를 운영자에게 전송하지 않습니다.
  2. 이 앱이 통신하는 대상은 GitHub의 서비스로 한정됩니다. 계정 확인을 위해 GitHub로부터 받은 이용자 정보(로그인명, 표시 이름, 계정 식별자)는 화면 표시와 제4항의 커밋 작성자 정보 구성에 사용되며, 이용자 컴퓨터를 벗어나 별도로 전송되지 않습니다.
  3. 이 앱이 이용자 컴퓨터에 저장하는 정보는 다음과 같습니다. 액세스 토큰 및 승인된 권한 범위는 운영체제 자격 증명 저장소에, 그 밖의 설정값은 Windows 레지스트리의 응용 프로그램 설정 영역에 저장됩니다. 설정값에는 최근 사용한 폴더 경로(최대 12개), 마지막으로 선택한 공개·비공개 설정, 마지막으로 입력한 커밋 메시지, 마지막으로 확인된 GitHub 로그인명이 포함됩니다.
  4. Git 커밋에는 작성자 이름과 이메일이 기록되고, 공개 저장소에 푸시하면 이 정보가 공개될 수 있습니다. 이 앱은 설정 화면의 「커밋에 내 이메일 숨기기」 옵션(기본 켜짐)이 켜져 있으면, 해당 커밋에 한하여 GitHub 표시 이름과 users.noreply.github.com 형식의 대체 이메일을 사용할 수 있습니다. 옵션을 끈 경우 이용자 컴퓨터의 Git 작성자 설정(user.name, user.email)이 있으면 그 값이 사용될 수 있습니다.
  5. 어느 경우에도 이 앱은 이용자 컴퓨터의 전역 Git 설정을 변경하지 않으며, 커밋 작성자 보완 정보는 해당 커밋에만 일시적으로 적용됩니다.

제14조 (무보증)

이 앱은 무상으로 "있는 그대로(as is)" 제공됩니다. 운영자는 이 앱이 중단 없이 동작하거나 오류가 없을 것, 특정 목적에 적합할 것, 이용자가 의도한 결과를 얻을 것을 보증하지 않습니다.

제15조 (책임의 제한)

  1. 운영자는 이용자가 이 앱을 사용하는 과정에서 발생한 파일의 손실·손상, 의도하지 않은 공개, 비밀 정보의 노출, 저장소 내용의 변경에 대하여 고의 또는 중대한 과실이 없는 한 책임을 지지 않습니다.
  2. 운영자는 이용자가 제7조 제4항의 백업 의무 및 제8조의 확인 의무를 이행하지 아니하여 확대된 손해에 대하여 책임을 지지 않습니다.
  3. 이 앱은 무상으로 제공되므로, 관련 법령이 허용하는 범위에서 운영자가 부담하는 금전적 책임은 없습니다.
  4. 이 조항은 법령에 따라 제한할 수 없는 책임을 배제하지 않습니다.

제16조 (지식재산권 및 오픈소스)

  1. 이 앱에 대한 저작권은 운영자에게 있으며, 이 앱의 배포 조건은 Apache License 2.0 에 따릅니다. 라이선스 전문은 저장소의 LICENSE 파일에 있으며, 이용자는 같은 라이선스가 정한 조건에 따라 이 앱을 사용·복제·수정·재배포할 수 있습니다.
  2. 이용자가 이 앱을 통해 게시한 저작물의 권리는 이용자 또는 정당한 권리자에게 있습니다. 운영자는 그 내용에 대한 권리를 주장하지 않습니다.
  3. 이 앱은 제3자 오픈소스 구성요소를 포함하며, 각 구성요소는 해당 라이선스의 조건에 따릅니다. 목록은 앱 내 설정의 오픈소스 고지에서 확인할 수 있습니다.

제17조 (서비스의 변경 및 중단)

운영자는 이 앱의 기능을 변경하거나 배포 및 지원을 중단할 수 있습니다. 이 앱은 이용자 컴퓨터에서 실행되므로 지원 중단 이후에도 설치된 프로그램은 계속 동작할 수 있으나, GitHub의 정책 또는 인터페이스 변경으로 기능이 동작하지 않을 수 있습니다.

제18조 (준거법 및 분쟁 해결)

이 약관은 대한민국 법령에 따라 해석되며, 이 앱의 이용과 관련하여 분쟁이 발생한 경우 당사자는 성실히 협의하여 해결합니다. 협의가 이루어지지 않는 경우 관할 법원은 민사소송법이 정하는 바에 따릅니다. 운영자는 특정 법원을 전속 관할로 지정하지 않습니다.
